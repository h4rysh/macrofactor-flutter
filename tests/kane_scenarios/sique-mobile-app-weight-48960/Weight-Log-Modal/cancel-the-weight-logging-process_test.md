# Cancel the weight logging process

## Step 1
Cancel the weight logging process. From the main dashboard, observe the current state of the weight chart. Get the current state of the weight chart and save as {{weight_chart_state}}. Open the weight logging modal using the Log Weight button or icon and cancel the action using the Cancel button or the 'X' icon. Observe the weight chart again and compare the weight chart state with {{weight_chart_state}}, ensuring no changes are saved and the app state remains the same.
