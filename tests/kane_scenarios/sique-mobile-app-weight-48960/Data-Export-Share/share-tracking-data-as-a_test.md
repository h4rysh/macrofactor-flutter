# Share tracking data as a file with another application

## Step 1
Share tracking data as a file with another application

Verifies a user can export their tracking data as a file, which invokes the native system share sheet for sharing with other apps.

Export tracking data as a file from the More tab through Settings, Export Data, and Share as File.
Verify the share sheet contains a file attachment.
Select a target application from the share sheet (e.g., an email client or cloud storage app).
Complete the share action in the target application (e.g., send the email).
