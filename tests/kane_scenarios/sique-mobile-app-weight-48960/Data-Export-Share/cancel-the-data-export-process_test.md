# Cancel the data export process from the share sheet

## Step 1
Cancel the data export process from the share sheet.

Ensures that if a user initiates a file share export and then cancels it from the native share sheet, the app returns to its previous state without exporting data.

Navigate to Export Data from the More tab in Settings. Share as File. Dismiss the share sheet by tapping outside of it or using the designated cancel action. Check a potential target application (e.g., email drafts, cloud storage).
