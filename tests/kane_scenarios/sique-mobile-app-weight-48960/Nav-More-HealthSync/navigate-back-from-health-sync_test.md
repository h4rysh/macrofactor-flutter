# Navigate back from Health Sync settings to the More screen

## Step 1
Launch the Sique mobile app and navigate to the main dashboard. Navigate to the 'Health Sync' settings screen from the main 'More' screen. Navigate back from the 'Health Sync' settings screen to the main 'More' screen using the back button, back arrow icon in the header, or system back gesture. Verify the current screen is the 'More' screen.
