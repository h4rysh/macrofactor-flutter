# Verify fat macro is not clamped for a moderate weight gain target

## Step 1
Verify fat macro is not clamped for a moderate weight gain target

A user sets a moderate rate of weight gain that keeps the calorie target below the fat clamping threshold, and verifies all macros scale proportionally without clamping.

Launch the Sique mobile app.
On the 'Goal' screen, adjust the target rate of weight gain to a moderate value (e.g., +0.5 lbs/week).
Proceed through the wizard to confirm the changes.
Observe the updated macro program details.
Verify the 'Fat' macro value.
Verify the 'Protein' and 'Carbs' macro values.
