# Discard strategy changes using system back navigation

## Step 1
Navigate to the **Strategy** screen. Edit and adjust the target rate of weight gain to a new value (e.g., +0.5 lb/week). Trigger the system's back navigation (e.g., swipe from edge or tap the back button). Tap the **Discard** button on the confirmation dialog. Verify the calorie target on the **Strategy** screen.
