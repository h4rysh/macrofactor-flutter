# Discard strategy changes using the wizard's cancel button

## Step 1
Discard strategy changes using the wizard's cancel button. Navigate to the main **Strategy** screen. Adjust the target rate of weight loss to a new value (e.g., -1.0 lb/week) in the wizard, then tap the **Cancel** or **X** button in the wizard's header. Verify the user is returned to the **Strategy** screen. Check the displayed calorie target.
