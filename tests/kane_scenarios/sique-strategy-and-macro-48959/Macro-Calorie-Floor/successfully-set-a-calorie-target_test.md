# Successfully set a calorie target exactly at the 1200 kcal safety floor

## Step 1
Successfully set a calorie target exactly at the 1200 kcal safety floor

A user sets a weight loss goal that results in a daily calorie target exactly at the 1200 kcal boundary, which the system should accept and save correctly.

Navigate to the main **Strategy** screen and edit the target rate of weight loss until the calculated 'Daily Calorie Target' displays exactly '1200'.
Verify the **Confirm** or **Save** button is enabled.
Confirm or save the target rate of weight loss.
Verify the updated calorie target on the **Strategy** screen.
