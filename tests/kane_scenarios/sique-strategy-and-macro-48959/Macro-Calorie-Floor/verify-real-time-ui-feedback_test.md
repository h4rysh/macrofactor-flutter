# Verify real-time UI feedback when approaching the calorie floor

## Step 1
Verify real-time UI feedback when approaching the calorie floor.

Navigate to the main **Strategy** screen. Tap the **Edit** button in the AppBar. Adjust the slider or input for 'Rate of Weight Loss' towards the maximum weight loss setting, then to the maximum possible value. Observe the UI around the calorie target.
